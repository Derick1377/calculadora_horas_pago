#Calculadora de Horas y Pago
##Problema que atiende
Ayuda a calcular cuánto dinero gana una persona según las horas trabajadas y lo que cobra por hora.
##Usuario principal
Un empleado que quiera saber cuánto ganó trabajando.
## Descripción
Este programa permite calcular cuánto dinero gana una persona según las horas que trabajó.
El usuario entra sus horas trabajadas y cuánto cobra por hora. El programa utiliza esos 
datos para calcular el pago. Luego muestra el resultado al usuario.
